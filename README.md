# BLV Data Viz

Interactive data visualization app for exploring BLV research data — charts, participant profiles, neural maps, and evidence exploration.

**[Live project →](https://github.com/susanchapas/BLV-data-viz)**

## Tech Stack

| Layer | Technology |
|-------|------------|
| Framework | React 18 + TypeScript 6 |
| Build | Vite 8 |
| Styling | Tailwind CSS 4 |
| Routing | React Router 7 |
| Charts | visx (axis, scale, shape, grid, tooltip) |
| Force layouts | d3-force |
| Animation | Framer Motion |
| Virtualization | TanStack Virtual |
| Linting | oxlint |
| Testing | Vitest, Testing Library, Playwright, axe-core |

## Getting Started

```sh
npm install
npm run dev
```

## Scripts

| Command | Description |
|---------|-------------|
| `npm run dev` | Start dev server |
| `npm run build` | Type-check and build for production |
| `npm run preview` | Preview production build |
| `npm run lint` | Lint with oxlint |
